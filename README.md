# P.A.N.D.E.M.I.C. 收容協議

手機同步的負數競拍原型。主持人可從電腦開局與結算；玩家以手機瀏覽器加入；大螢幕頁面則公開顯示市場、樣本、資源與排名。

## 啟動

最簡單的方式是直接雙擊 `開始遊戲.command`。第一次開啟 macOS 若出現安全性提示，請在 Finder 對檔案按右鍵，選擇「打開」，再按一次「打開」。

它會自動開啟主持人控制台，並在跳出的視窗顯示手機加入網址。活動期間請不要關閉該視窗；結束時在該視窗按 `Control + C`。

如果你熟悉終端機，也可以在本資料夾執行：

```bash
node server.js
```

接著在主持人電腦開啟 `http://localhost:3000`。若玩家和主持人使用相同 Wi-Fi，請改以該電腦的區域網路 IP 開啟，例如 `http://192.168.1.20:3000/player.html`。

## 活動操作

1. 主持人在 `/host.html` 打開控制台；玩家從 `/player.html` 輸入名稱加入。
2. 將 `/screen.html` 投放到大螢幕。
3. 按「啟動下一輪市場」：系統會將玩家隨機分到最多五個平行市場。
4. 每個市場依序讓玩家在手機上選擇拒絕（花 1 點隔離資源）或收容；收容者取得樣本與拒絕池。
5. 所有市場完成後，按「結算本回合」，再開始下一輪。

分數為：剩餘隔離資源，減去各連號樣本群組中風險最低的數值。也就是相鄰風險值會被視為同一份抗原圖譜，只計一次風險。

## 活動正式版：公開網址

現場若使用學校、飯店或公共 Wi-Fi，請使用公開雲端版本，不要使用同網路連線版。雲端版本會提供一個 HTTPS 網址；主持人、投影電腦與每一部手機可使用不同網路或行動數據連入。

本專案已附上 Render 的部署設定（`render.yaml`）。在 Render 建立付費 Web Service 時選擇此資料夾／儲存庫即可。部署完成後，在服務的 Environment 頁面取得 `HOST_KEY`，這是只有主持人能開局、結算及重置的密鑰；第一次按主持人按鈕時輸入一次即可。
