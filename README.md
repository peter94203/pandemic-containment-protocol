# P.A.N.D.E.M.I.C. 收容協議

手機同步的負數競拍原型。主持人可從電腦開局與結算；玩家以手機瀏覽器加入；大螢幕頁面則公開顯示市場、樣本、資源與排名。

## 啟動

最簡單的方式是直接雙擊 `開始遊戲.command`。第一次開啟 macOS 若出現安全性提示，請在 Finder 對檔案按右鍵，選擇「打開」，再按一次「打開」。

它會自動開啟主持人控制台，並在跳出的視窗顯示手機加入網址。活動期間請不要關閉該視窗；結束時在該視窗按 `Control + C`。

如果你熟悉終端機，也可以在本資料夾執行：

```bash
node server.js
```

接著在主持人電腦開啟 `http://localhost:3000`。若玩家和主持人使用相同 Wi-Fi，請改以該電腦的區域網路 IP 開啟，例如 `http://192.168.1.20:3000/player.html`。

## 活動操作

1. 主持人在 `/host.html` 打開控制台；玩家從 `/player.html` 輸入名稱加入。
2. 將 `/screen.html` 投放到大螢幕。
3. 玩家都加入後，主持人按「開啟下一回合市場」。第一下會固定發出 5 名反收容派與所有私密身份；每位玩家必須在手機確認。
4. 全員確認後，主持人再按一次開啟第 1 輪市場。每回合同時公開 A～E 五個市場；每位玩家可申請收容多張樣本，或全部拒絕。
5. 有申請者的樣本依「無樣本者、隔離點數較多者、持有樣本較少者、抽籤」的順序決定收容者。無人申請的樣本會保留；每位玩家各扣 1 點，並累積到該樣本的拒絕池。
6. 全部五張樣本在第一次決策就售出時，失控指數 −2；同輪有兩張以上被反收容派收容時，失控指數 +2。無人申請而留在市場的樣本每輪使失控指數 +1。
7. 第 2 輪起，好人可每輪匿名舉報一名玩家。被舉報至 9 點將公開陣營，並依陣營調整失控指數。
8. 主持人頁面下方的「私有監控」只會顯示在主持人電腦：可看見真實身份、陣營、送出的選擇、舉報點與延遲效果。大螢幕不會顯示這些資訊。
9. 活動結束時由主持人按「鎖定失控指數並最終結算」。未消除的危險係數 15 以上樣本會各使失控指數 +1；達 10 即由反收容派獲勝。

分數為：隔離點數，減去未消除的樣本風險。病毒、細菌、寄生蟲同類型的連續三個以上數字可全部消除；相同數字的病毒、細菌、寄生蟲三張也可全部消除。若有重疊組合，系統會自動採用對玩家最有利的消除方式。

所有好人身份均已可直接運作：三種病原專家、免疫學家、研發天才、基因定序師、疫苗開發員、收容指揮官、生物安全官、流行病學專家、跨域研究員、緊急應變員與病原體獵人。五種反收容派身份均可從手機使用其限制次數的隱密行動。

## 活動正式版：公開網址

現場若使用學校、飯店或公共 Wi-Fi，請使用公開雲端版本，不要使用同網路連線版。雲端版本會提供一個 HTTPS 網址；主持人、投影電腦與每一部手機可使用不同網路或行動數據連入。

本專案已附上 Render 的部署設定（`render.yaml`）。在 Render 建立付費 Web Service 時選擇此資料夾／儲存庫即可。部署完成後，在服務的 Environment 頁面取得 `HOST_KEY`，這是只有主持人能開局、結算及重置的密鑰；第一次按主持人按鈕時輸入一次即可。
